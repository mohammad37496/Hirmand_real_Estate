# املاک هیرمند — اپ کارکنان

این پوشه یک پروژه Android مستقل برای کارکنان بنگاه است.

## استقلال

این اپ عمداً هیچ کدی از پروژهٔ قدیمی Phone Bridge را import یا reuse نمی‌کند و به زیرساخت Phone Bridge، APIهای `device-sync`، دیتابیس سایت، توکن دستگاه یا سرویس‌های قبلی متصل نیست.

- namespace: `ir.hirmand.staff`
- applicationId: `ir.hirmand.staff`
- نسخه اولیه: `0.1.0`
- حداقل Android: API 26
- target/compile: API 35
- Java/Kotlin target: 17

## وضعیت فعلی

صفحهٔ پایهٔ اپ با نام **املاک هیرمند** ساخته شده است. پس از پذیرش توافق‌نامه، کاربر باید یکی از کارکنان فعلی بنگاه را انتخاب و ثبت کند؛ شناسهٔ کارمند و زمان ثبت فقط به‌صورت محلی روی همان گوشی ذخیره می‌شوند. تا پیش از این ثبت، ورود به صفحهٔ اصلی اپ ممکن نیست. در این مرحله هیچ داده‌ای از گوشی جمع‌آوری یا به اینترنت ارسال نمی‌شود.

اتصال به سایت، سرور، حساب کاربری، اعلان‌ها، همگام‌سازی و قابلیت‌های تخصصی کارکنان عمداً برای مرحلهٔ بعدی گذاشته شده‌اند.
