# همراه هیرمند — Android Companion

این پروژه یک کلاینت مستقل اندروید برای اتصال **صریح و قابل مشاهده** یک دستگاه به زیرساخت همگام‌سازی هیرمند است.

## امکانات فعلی

- جفت‌سازی یک‌بارمصرف با کدی که پنل ادمین تولید می‌کند.
- نگهداری توکن دستگاه با Android Keystore و AES-GCM.
- صف آفلاین محلی با SQLite.
- همگام‌سازی دسته‌ای تا 100 رویداد و idempotency سمت سرور.
- Sync دستی و Sync دوره‌ای با WorkManager وقتی شبکه در دسترس است.
- ثبت وضعیت دستگاه: مدل، نسخه اندروید، باتری و وضعیت اتصال شبکه.
- ارسال **موقعیت فعلی فقط با اقدام مستقیم کاربر** و با مجوز سیستم.
- بدون Firebase/FCM و بدون وابستگی هسته‌ی Sync به سرویس‌های خارجی.

## اجرای محلی

این پوشه را با Android Studio باز کن. پروژه با Android Gradle Plugin 9.4.0 و Gradle 9.6.0 تنظیم شده و روی compileSdk 36 ساخته می‌شود.

برای ساخت Debug APK:

```text
gradle -p android assembleDebug
```

خروجی:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## حریم خصوصی

این کلاینت فقط رویدادهایی را ارسال می‌کند که خود اپ تولید کرده است. موقعیت مکانی در پس‌زمینه فعال نیست و ضبط/رهگیری مخفی تماس، پیام یا اطلاعات اشخاص دیگر در این پروژه پیاده‌سازی نشده است.
